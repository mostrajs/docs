# Lessons

This catalog indexes the focused lessons of this repository. Route the task first, then read only
records whose areas or topics match the work.

## How to use this catalog

1. Add every matching area: `site`, `docs-sync`, `tooling`.
2. Use topics to narrow cross-cutting concerns such as `fumadocs`, `astro` or `netlify`.
3. Open only the linked records that match; do not bulk-read `.ai/lessons/`.

Add a lesson as one kebab-case record in `.ai/lessons/` plus one row here. Hard safety and
workflow rules belong in `AGENTS.md`; a lesson carries the evidence, the failure mode, and the
durable rule.
